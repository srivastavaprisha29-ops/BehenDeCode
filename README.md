## `01 / WHAT IS THIS?`

**Behen DeCode** is the website behind the YouTube channel.

A place for movies we need to discuss, books we can't stop thinking about, code we're trying to make work, academics when academics unfortunately become necessary, and conversations about everything in between.

Sometimes it's the two of us.

Sometimes it's one of us.

Sometimes it's useful.

Sometimes it's a movie discussion that somehow became a conversation about life.

**That's kind of the point.**

## `04 / DeCODE: CODE` 💻

Somewhere between the movies and the coffee, there is in fact **code**.

```python
from datetime import datetime

class BehenDeCode:

    def __init__(self):
        self.coffee = True
        self.open_tabs = 37

        self.topics = [
            "movies",
            "books",
            "code",
            "college",
            "life"
        ]

    def decode(self, topic):
        research(topic)
        talk_about_it(topic)
        overthink_it_slightly(topic)

        return make_something(topic)


channel = BehenDeCode()

while True:
    channel.decode(whatever_we_are_into_this_week)
```

## `10 / WHY`

There are enough places online telling people to pick a niche.

This isn't one of them.

You can care about technology **and** movies.

Read classics and watch ridiculous television.

Talk about academics and then spend forty minutes discussing a fictional character.

Make something useful and something completely unnecessary.

Be serious about what matters without being serious all the time.

**Behen DeCode is simply where all of those things get to exist in the same place.**
